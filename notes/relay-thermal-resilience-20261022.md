# Local relay resilience

The dedicated authenticated Firefox relay tab is recreated if closed or navigated
away. Other tabs are not closed, cookies are not extracted, and a missing/expired
owner session remains an explicit hold. This does not claim browser-independent
M2M authentication. The existing original-event readback remains mandatory.
Automatic size work prioritizes newer rows and stays asynchronous in the dedicated
tab so server vision latency does not hold photo dispatch.

Only auxiliary Rescue shadow is paused at >=85 C, with resume at <=78 C. The
supervisor signals only the exact rescue_shadow.py live worker inside Frigate;
it does not stop Frigate, change its start schedule or alter detection thresholds.
Heavy Ojala evidence roots were excluded from desktop indexing with .trackerignore
and the desktop indexer's CPU was capped at 10% for the current user session.
No photographs or videos were deleted. Physical cooling inspection is still
unverified; these are workload protections, not a repaired fan.
